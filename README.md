# Moonli Calm Landing

Landingpage für Moonli, den Baby- und Elternbegleiter für Schlaftracking, Wachfenster, Erinnerungen und ruhigere Familiennächte.

## Live

https://chmolnar-byte.github.io/moonli-calm-landing/

## Entwicklung

Voraussetzung: Node.js und npm.

```bash
npm i
npm run dev
```

Lokale Vorschau: http://localhost:8080/

## Build

```bash
npm run build
```

## Bildoptimierung

```bash
node scripts/optimize-images.mjs
node scripts/generate-seo-assets.mjs
```

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
